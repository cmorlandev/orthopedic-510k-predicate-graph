# Re-run instructions — frozen text + Rule 2 (September 2026)

What this run does, in one line each:
1. **Freezes** the extracted text you already have in `data/text/` so nobody's numbers depend on what FDA's server happens to serve that day (DEVIATIONS D5).
2. **Re-mines the edges under two rules**: Rule 1 (the registered rule, unchanged) and Rule 2 (Rule 1 minus compatibility-table and reference-device citations; DEVIATIONS D4). Rule 2 becomes the primary analysis.
3. **Re-runs Stages 6–8** on Rule 2, with Rule 1 and the other post hoc arms reported as sensitivity analyses (D6).

Nothing touches `snapshot/`, and nothing re-downloads PDFs. Stage 0, 1, 2, 4 and 5 outputs are reused as-is.

Total hands-on time is about 30 minutes; Stage 7 runs ~15 minutes unattended.

---

## Before you start

Open Terminal, go to the repo, and make sure the environment is the pinned one:

```bash
cd ~/predicate-study
python --version          # 3.11.x
git status                # commit or stash anything uncommitted first, so the diff of this run is clean
git checkout -b rule2-rerun
```

Confirm the text corpus is complete (12,388 files, one per retrieved summary):

```bash
ls data/text | wc -l      # expect 12388
```

If the count is lower, do not proceed; something was deleted and you need the PDFs re-extracted first (run only the extraction cell of the *old* Stage 3 from git history, or ask me).

## Step 1 — Unit-test the new rule (10 seconds)

```bash
python test_edge_rules.py
```

Expect five `ok` lines. Two of the tests use the real text of K190123 and K050441 — the documents that carried every false positive in the validation sample — and assert that Rule 2 keeps exactly their true predicates (K170444; K921301 and K943230) and drops the rest.

## Step 2 — Freeze the text (about 1 minute)

```bash
python freeze_text.py
python freeze_text.py --check     # sanity: should print PASS
git add TEXT_SNAPSHOT.json TEXT_SNAPSHOT_files.csv
```

This writes per-file SHA-256 hashes and one corpus hash. Copy the corpus hash into `RUN_LOG.md` Part Five.

## Step 3 — Stage 3 (about 10 minutes)

In JupyterLab, launched from the repo root: open `03_extract_edges.ipynb`, **Run All Cells**.

It will refuse to run if `data/text/` doesn't match the freeze — that is the point.

Check the printout:
- Rule 1 edges should be **30,476** exactly (your August number). If it isn't, stop and tell me — it means the text corpus differs from your August run.
- Rule 2 edges will be lower. Gant's estimate implies roughly 27,000; anywhere in 26,500–28,000 is plausible. Note the excluded count and the compat/reference split.
- `data/excluded_edges.csv` now lists every removed edge with the heading that removed it. **Send this file to Gant** — he joins it against his adjudication CSV to confirm the rule removes what he rejected and nothing he accepted.

## Step 4 — Stage 6 and Stage 8 (about 2 minutes)

Run All on `06_graph_and_analysis.ipynb`, then `08_verify.ipynb`.

- `sens_maximal_rule` in the Stage 6 printout should be **(938, 2877, 1873)** — that is the Rule 1 graph, so it must reproduce your August H1 triple exactly. If it does, the freeze worked and the only thing that changed is the rule.
- Stage 8 should say **17/17**.
- If you want the §9 non-pilot panel, create `pilot_codes.txt` at the repo root with the nine pilot product codes, one per line, **before** running Stage 6. Without that file the panel is skipped with a note.

## Step 5 — Stage 7 (about 15 minutes, needs `OPENFDA_KEY`)

```bash
export OPENFDA_KEY=your_key
```

Run All on `07_maude.ipynb`. The recalled-predicate set changes slightly under Rule 2, so this has to be re-run. It now also prints and saves the **linked-only** comparison.

Open a PR so Gant can run `python compare_to_reference.py` on the frozen inputs. His run must now match **every** field exactly — there is no drift tier anymore.

## Step 7 — Upload to OSF

Add `data/text/` (zipped, ~120 MB) to the OSF project next to `snapshot/`. That plus the hashes in git is what makes the study reproducible by someone who has never touched FDA's server.

## If something goes wrong

- **Stage 3 assertion "does not match TEXT_SNAPSHOT.json"** — you edited or regenerated a text file after freezing. Re-run `python freeze_text.py` only if you intended that; otherwise restore `data/text/`.
- **Rule 1 edges ≠ 30,476** — the text corpus is not the August one. Check `ls data/text | wc -l` and the manifest.
- **`sens_maximal_rule` ≠ (938, 2877, 1873)** — same cause, or `recalled_nodes.csv` changed. Don't proceed; tell me the numbers.
- **Rule 2 removes something Gant accepted as a predicate** — send me the K-numbers; the zone heuristics in `edge_rules.py` are meant to be tuned against his 266 verdicts before the numbers are final, and that tuning is part of what gets reported.
